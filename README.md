# Triz Agency

Landing page em Next.js baseada nas telas desktop e mobile do Figma “Site Triz Novo — Glow up”.

## Desenvolvimento

```bash
npm install
npm run dev
```

Acesse http://localhost:3000.

## Estrutura

- `src/app/page.tsx`: conteúdo, navegação mobile e serviços interativos.
- `src/app/globals.css`: estilos responsivos.
- `src/components/FigmaIllustration.tsx`: ilustração de contato composta pelos vetores do Figma.
- `public/figma/`: imagens e SVGs originais usados na página.
- `src/fonts/`: fontes da identidade visual.

`npm run build` verifica compilação e tipos.
